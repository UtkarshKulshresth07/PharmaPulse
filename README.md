# PharmaPulse 💊

A comprehensive Manager Dashboard for the Pharmaceutical Industry. This is a single-page application (SPA) built using HTML, CSS, and Vanilla JavaScript.

## 🚀 Features
- **Product Launch Strategy Simulator:** Analyze market entry strategies based on drug type and target market.
- **Sales Analytics:** Live interactive bar charts using Chart.js.
- **Market Share:** Doughnut chart for competitor analysis.
- **Profit Margin Calculator:** Real-time financial calculations.
- **MR Tracker:** Log doctor visits with specialties, search functionality, and target progress bars. Data is stored in LocalStorage.

## 🛠️ Tech Stack
- HTML5 / CSS3
- Vanilla JavaScript
- Chart.js (for data visualization)
- LocalStorage (for saving data in the browser)
